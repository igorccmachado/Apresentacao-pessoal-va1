# Página Pessoal - Igor Chagas Carvalho Machado

## Descrição

Este projeto consiste em uma página pessoal criada para apresentar um pouco
sobre Igor Chagas Carvalho Machado, seus interesses, objetivos profissionais,
habilidades e tecnologias que deseja aprender.

## Objetivo

O objetivo da página é apresentar informações pessoais e profissionais,
destacando o interesse pela área de tecnologia e o objetivo de construir uma
carreira em tecnologia, inclusive com a possibilidade de trabalhar fora do
país.

## Tecnologias utilizadas

- HTML5
- CSS3
